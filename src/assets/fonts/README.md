# Bundled portfolio fonts

These are the existing Latin WOFF2 font assets previously downloaded by this project's `next/font/google` setup, now loaded through `next/font/local` for reproducible builds.

- Syne: normal, used at 700–800
- DM Sans: normal and italic, used at 400–700
- EB Garamond: normal and italic, used at 400
- JetBrains Mono: normal, used at 500

Each family is distributed under its accompanying SIL Open Font License. License sources: the corresponding `ofl/syne`, `ofl/dmsans`, `ofl/ebgaramond`, and `ofl/jetbrainsmono` directories in https://github.com/google/fonts.
